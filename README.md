# 📄 Resume Keyword Extractor

A simple and efficient Resume Keyword Extractor built with **Python** and **Streamlit**. This application allows users to upload a resume in `.txt` format and automatically extracts important information such as contact details, skills, education, experience, and projects using Regular Expressions (Regex).

---

## 🚀 Features

- Upload resume (.txt format)
- Extract Email Address
- Extract Phone Number
- Extract LinkedIn Profile
- Extract GitHub Profile
- Detect Technical Skills
- Detect Education Qualifications
- Extract Years of Experience
- Identify Project Names
- Simple and Interactive Streamlit UI

---

## 🛠 Technologies Used

- Python
- Streamlit
- Regular Expressions (Regex)

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/resume-keyword-extractor.git
```

Move into the project directory

```bash
cd resume-keyword-extractor
```

Install dependencies

```bash
pip install streamlit
```

---

## ▶️ Run the Project

```bash
streamlit run resume_keyword_extractor.py
```
